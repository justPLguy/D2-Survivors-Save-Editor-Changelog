# D2 Survivors Save Editor — Changelog

This repository holds **only the changelog** of the D2 Survivors Save Editor, plus `version.json`, which the editor reads to tell you when a newer version is live.

There is **no editor code and nothing to download here**.

## ▶ Use the editor

**https://d2-survivors-save-editor.justplguy.workers.dev/**

It runs fully in your browser: nothing to install, nothing to download, and your save never leaves your PC unless you choose to share it.
